ĐÂY LÀ ỨNG DỤNG HỖ TRỢ QUẢN LÝ CÁC TRANG TRONG TÀI LIỆU PDF

bao gồm 2 công cụ là pdfman và pdflock

1. pdfman: quản lý xoay trang, di chuyển trang, xóa trang, nối thêm pdf
   (có thể kéo thả hoặc mở 1 lần nhiều file PDF hoặc thêm nhiều file PDF)

2. pdflock: hỗ trợ khóa (lock)/mở khóa (unlock) các file PDF
   (không hỗ trợ bẻ khóa, remove password của các file PDF vì tác giả không có khả năng)
   Khi lock PDF sẽ sử dụng mã hóa AES-256, vì vậy nên khuyên người dùng
   đặt mật khẩu khó để bảo vệ PDF tốt hơn (tuy nhiên, cũng phải nhớ mật khẩu,
   nếu quên thì cũng rất khó mở lại PDF đó - riêng tác giả là không có cách nào)
